This is the code/data repository for the following report:

Potts, Christopher and Moritz Sudhof. 2026. Invisible failures in human--AI interactions. Ms., Bigspin and Stanford.

## Overview:

* `bigspin.mplstyle`: plot styling for the paper's figures
* `tag_transcripts.py`: implementation of the core annotation method
* `capability_interaction_tagger.py`: implementation of the behavior/capability tagging experiment
* `paper_stats_capability_interaction.py`: code for the behavior/capability analyses
* `techreport_analyses.ipynb`: Notebook for the paper's figures and analyses
* `techreport_utils.py`: Supporting functions or the notebook
* `data/`
    * `wildchat_bigspin_annotations_v1.json.gz`: The main dataset
    * `wildchat_bigspin_annotations_2k_gpt_v1.json.gz`: 2K sample with GPT-5.2 for comparison
    * `wildchat_bigspin_annotations_2k_opus_v1.json.gz`: 2k sample with Opus for comparison
* `fig/`: Contains all the plots used in the paper; `generated by techreport_analyses.ipynb`.


The 2K samples were created using the commands

```python tag_transcripts.py submit lm_ann_samp.csv --model "claude-opus-4-6" --output "wildchat_bigspin_annotations_2k_opus_v1.csv"```

```python tag_transcripts.py run lm_ann_samp.csv --provider openai --model "gpt-5.2" --sample None --output "wildchat_bigspin_annotations_2k_gpt_v1.csv"```

where `lm_ann_samp.csv` is a random sample from `fail_df` in `techreport_analyses.ipynb` using `random_state=42`.

The behavior/capability tagging experiment was done with:

```python capability_interaction_tagger.py --workers 20```
